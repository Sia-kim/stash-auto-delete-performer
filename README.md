# Stash Auto Delete Banned Performer (v1.1.9)

Stash(성인 미디어 관리 프로그램)에서 특정 배우가 출연하는 영상을 스캔 시 자동으로 감지하여 실제 비디오 파일까지 영구 삭제하는 플러그인입니다.

## ✨ 주요 기능
- **플로팅 UI**: 배우 상세 페이지 우측 하단에 제어판이 생성됩니다.
- **자동 삭제**: 등록된 배우(`AutoDeleteTarget` 태그)의 영상이 새로 스캔되면 즉시 파일을 삭제합니다.
- **일괄 삭제**: 기존 라이브러리에 있는 해당 배우의 모든 영상을 한 번에 삭제합니다. (50개 단위 분할 삭제로 서버 과부하 방지)
- **안전장치**: 삭제 전 발견된 영상 수를 확인하고, 배우 이름을 직접 입력해야 삭제가 진행됩니다.
- **비동기 최적화**: 페이지 이동 시 UI가 중복 생성되거나 사라지지 않도록 완벽한 동시성 제어(Lock & Queue)가 적용되어 있습니다.

## 🚀 설치 방법
1. Stash 웹 UI에서 `설정(Settings)` ➡️ `플러그인(Plugins)`으로 이동합니다.
2. `패키지 소스 추가(Add Source)`를 클릭합니다.
3. 아래 주소를 입력합니다.
   `https://sia-kim.github.io/stash-auto-delete-performer/index.yml`
4. `업데이트 확인`을 누른 뒤 플러그인을 설치합니다.

## ⚠️ 주의사항
- 이 플러그인은 `delete_file: true` 옵션을 사용하여 **실제 하드디스크의 비디오 파일을 영구 삭제**합니다.
- Stash 컨테이너가 영상 폴더에 대해 읽기/쓰기 권한을 가지고 있어야 합니다.
- 처음 사용하실 때는 반드시 **백업된 테스트 라이브러리**에서 충분히 검증하시길 권장합니다.
