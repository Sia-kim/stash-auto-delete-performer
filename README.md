# Stash Auto Delete Banned Performer (v1.2.6)

Stash(성인 미디어 관리 프로그램)에서 특정 배우가 출연하는 영상을 **안전하게 감지하여 실제 비디오 파일까지 영구 삭제**하는 플러그인입니다.

## ✨ 주요 기능
- **플로팅 UI**: 배우 상세 페이지 우측 하단에 제어판(등록/해제, 목록 보기, 수동 삭제)이 생성됩니다.
- **일괄 삭제**: `AutoDeleteTarget` 태그가 달린 배우의 모든 영상을 50개 단위로 분할 삭제하여 서버 과부하를 방지합니다.
- **철저한 안전장치**: 
  - 삭제 전 모든 배우와 씬을 사전 조회하여 **단 하나라도 조회에 실패하면 삭제를 중단**합니다.
  - Job Queue 응답이 비정상일 경우 삭제를 차단합니다.
  - 삭제 전 배우 이름을 직접 입력해야 실행됩니다.
- **외부 스케줄러 연동**: 브라우저 타이머에 의존하지 않고, **시놀로지 작업 스케줄러(Cron)** 등 외부 스케줄러가 Stash API를 호출하여 매일 정해진 시간에 자동 삭제를 실행합니다.

## 🚀 설치 방법
1. Stash 웹 UI에서 `설정(Settings)` ➡️ `플러그인(Plugins)`으로 이동합니다.
2. `패키지 소스 추가(Add Source)`를 클릭합니다.
3. 아래 주소를 입력합니다. (캐시 방지를 위해 `?v=26`을 붙이는 것을 권장합니다.)
   ```text
   https://sia-kim.github.io/stash-auto-delete-performer/index.yml?v=26
업데이트 확인을 누른 뒤 플러그인을 설치합니다.

⚙️ 시놀로지 스케줄러 연동 가이드 (필수)
이 플러그인은 브라우저가 꺼져 있어도 작동하도록 시놀로지 작업 스케줄러와 연동하여 사용하는 것을 권장합니다.

시놀로지 DSM ➡️ 제어판 ➡️ 작업 스케줄러 ➡️ 생성 ➡️ 예약된 작업 ➡️ 사용자 정의 스크립트를 클릭합니다.

일반 탭: 작업 이름 Stash Auto Delete, 사용자 root 선택.

일정 탭: 매일, 원하는 시간(예: 오전 5:00 - 스캔 시작 전) 설정.

작업 설정 탭의 스크립트 란에 README 하단의 '시놀로지 스크립트' 내용을 붙여넣습니다. (IP, 포트, API 키 수정 필수)

⚠️ 주의사항
이 플러그인은 delete_file: true 옵션을 사용하여 실제 하드디스크의 비디오 파일을 영구 삭제합니다.

Stash 컨테이너가 영상 폴더에 대해 읽기/쓰기 권한을 가지고 있어야 합니다.

처음 사용하실 때는 반드시 백업된 테스트 라이브러리에서 충분히 검증하시길 권장합니다.
